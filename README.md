# Employee Payroll Management System

## 📌 Project Overview

The **Employee Payroll Management System** is a C programming project designed to manage employee payroll efficiently. It automates salary calculations, maintains employee records, and generates detailed salary reports.

The system helps reduce manual calculations, minimize human errors, and simplify the process of managing employee salary information.

## 🎯 Objectives

- To maintain employee information such as name and employee ID.
- To calculate employee net salaries automatically.
- To manage salary components such as basic salary, allowances, and deductions.
- To generate individual employee salary slips.
- To prepare financial summaries and payroll reports.
- To demonstrate the practical implementation of C programming concepts.

## 🛠️ Technologies Used

- **Programming Language:** C
- **Compiler:** GCC / Turbo C
- **Code Editor:** Visual Studio Code
- **Operating System:** Windows / Linux

## 📚 Concepts Used

This project implements the following C programming concepts:

1. **Structures:** To store employee details and salary information.
2. **Arrays:** To manage multiple employee records.
3. **Functions:** To perform salary calculations and generate reports.
4. **Pointers:** To access and manipulate employee data.
5. **Dynamic Memory Allocation:** To allocate memory for employee records at runtime.
6. **Loops and Conditional Statements:** To process employee information.

## 💰 Salary Calculation

The net salary of an employee is calculated using the following formula:

**Net Salary = Basic Salary + Allowances − Deductions**

Where:

- Basic Salary: The fixed salary of an employee.
- Allowances: Additional payments such as HRA and other benefits.
- Deductions: Amounts deducted from salary.

## ⚙️ Features

- Add and manage employee details.
- Store employee ID and name.
- Enter basic salary, allowances, and deductions.
- Automatically calculate net salary.
- Generate individual salary slips.
- Display payroll reports.
- Calculate total salary expenses.

## 🚀 How to Run the Project

### Step 1: Clone or Download the Repository

Download the project files to your computer.

### Step 2: Open the Project

Open the project folder in Visual Studio Code or any C compiler.

### Step 3: Compile the Program

Using GCC, execute:

```bash
gcc payroll.c -o payroll
```

### Step 4: Run the Program

For Windows:

```bash
payroll.exe
```

For Linux:

```bash
./payroll
```
